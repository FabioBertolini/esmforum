# Instalação do Ambiente - ESM Forum

## Repositórios Utilizados

Backend:
https://github.com/FabioBertolini/esmforum

Frontend:
https://github.com/FabioBertolini/esmforum-react

---

## Requisitos

- Node.js 20 LTS
- NPM
- VS Code

---

## Instalação do Backend

1. Clonar ou baixar o repositório esmforum.
2. Abrir a pasta do projeto no VS Code.
3. Executar:

```bash
npm install
```

4. Iniciar o servidor:

```bash
node server.js
```

O backend ficará disponível em:

```text
http://localhost:5000
```

---

## Instalação do Frontend

1. Clonar ou baixar o repositório esmforum-react.
2. Abrir a pasta do projeto no VS Code.
3. Executar:

```bash
npm install
```

4. Iniciar a aplicação:

```bash
npm start
```

O frontend ficará disponível em:

```text
http://localhost:3000
```
