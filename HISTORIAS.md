# Histórias de Usuário

## História 1: Busca de Perguntas por Palavra-chave

**Como** usuário do fórum,

**Eu quero** pesquisar perguntas por palavras-chave,

**Para** encontrar rapidamente conteúdos relacionados ao meu interesse.

**Critérios de Aceitação:**

- [ ] Deve existir um campo de busca visível na interface.
- [ ] O sistema deve listar perguntas que contenham a palavra pesquisada.
- [ ] A busca deve ignorar diferenças entre letras maiúsculas e minúsculas.
- [ ] Caso não existam resultados, o sistema deve informar ao usuário.
- [ ] Os resultados devem ser exibidos sem necessidade de recarregar a página.

---

## História 2: Categorização de Perguntas

**Como** usuário do fórum,

**Eu quero** associar categorias às perguntas,

**Para** organizar melhor os conteúdos publicados.

**Critérios de Aceitação:**

- [ ] O usuário deve poder selecionar uma categoria ao criar uma pergunta.
- [ ] Cada pergunta deve possuir uma categoria associada.
- [ ] As categorias devem ser exibidas junto às perguntas.
- [ ] O sistema deve disponibilizar categorias pré-definidas.
- [ ] Deve ser possível filtrar perguntas por categoria.

---

## História 3: Sistema de Votação em Perguntas

**Como** usuário do fórum,

**Eu quero** votar positivamente ou negativamente em perguntas,

**Para** destacar conteúdos mais relevantes para a comunidade.

**Critérios de Aceitação:**

- [ ] Cada pergunta deve exibir botões de voto positivo e negativo.
- [ ] O total de votos deve ser exibido ao usuário.
- [ ] Um usuário não pode votar mais de uma vez na mesma pergunta.
- [ ] O usuário deve poder alterar seu voto.
- [ ] A contagem de votos deve ser atualizada após a votação.

---

# Priorização

## Prioridade 1
Busca de perguntas por palavra-chave

## Prioridade 2
Categorização de perguntas

## Prioridade 3
Sistema de votação em perguntas

## Justificativa

A busca de perguntas foi definida como prioridade máxima por melhorar diretamente a experiência de uso do fórum e facilitar o acesso às informações.

A categorização complementa a funcionalidade de busca, permitindo melhor organização dos conteúdos.

O sistema de votação foi colocado em terceiro lugar por agregar valor à comunidade, mas depender da existência de conteúdo organizado para gerar melhores resultados.
