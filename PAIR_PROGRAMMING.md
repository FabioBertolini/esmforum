# Planejamento de Pair Programming

## Estratégia de Aplicação

O projeto está sendo desenvolvido individualmente. Entretanto, caso houvesse um parceiro de desenvolvimento, a prática de Pair Programming seria aplicada para aumentar a qualidade do código e reduzir a ocorrência de erros.

A estratégia adotada seria a programação em pares durante a implementação das funcionalidades mais importantes do sistema, especialmente aquelas que envolvem alterações simultâneas no frontend e no backend.

---

## Papéis

### Driver

Responsável por:

- Escrever o código.
- Realizar alterações nos arquivos.
- Executar testes.
- Implementar as soluções discutidas pela dupla.

### Navigator

Responsável por:

- Revisar o código em tempo real.
- Identificar possíveis erros.
- Sugerir melhorias.
- Verificar aderência aos requisitos.
- Auxiliar na tomada de decisões técnicas.

---

## Rotação de Papéis

Os papéis seriam alternados periodicamente durante o desenvolvimento.

Uma possível estratégia seria realizar a troca a cada funcionalidade implementada ou a cada período de trabalho definido pela equipe.

Essa abordagem permite que ambos os integrantes participem das decisões e compartilhem conhecimento sobre todo o sistema.

---

## Ferramentas

As ferramentas que poderiam ser utilizadas para aplicação do Pair Programming são:

- Visual Studio Code Live Share
- Discord
- Google Meet
- Microsoft Teams

Essas ferramentas permitem compartilhamento de tela, comunicação em tempo real e colaboração simultânea no código.

---

## Benefícios Esperados

A aplicação de Pair Programming pode proporcionar:

- Redução de erros durante a implementação.
- Compartilhamento de conhecimento.
- Melhor qualidade do código.
- Maior aderência aos requisitos do projeto.
- Identificação antecipada de problemas de design e implementação.

---

## Conclusão

Embora o desenvolvimento deste projeto esteja sendo realizado individualmente, a prática de Pair Programming poderia ser aplicada de forma eficiente utilizando ferramentas de colaboração remota, permitindo revisão contínua do código e melhoria da qualidade das entregas.
